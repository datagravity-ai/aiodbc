# pyodbc

pyodbc is an open source Python module that makes accessing ODBC databases simple.  It
implements the [DB API 2.0](https://www.python.org/dev/peps/pep-0249) specification with an
asyncio-native API, and is implemented in Rust as of version 6.0.

The easiest way to install is to use pip:

    pip install pyodbc

Precompiled binary wheels are provided for most Python versions on Windows, macOS, and Linux.
On other operating systems this will build from source (requiring a Rust toolchain and the
unixODBC headers).

The rest of the pyodbc documentation is now on a Wiki so it can be maintained by the entire community.

[pyodbc Documentation](https://github.com/mkleehammer/pyodbc/wiki)
